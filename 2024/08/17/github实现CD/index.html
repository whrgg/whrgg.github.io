Actions基本使用方法

基本概念

  • workflow：GitHub的配置文件，存放在.github/workflow文件夹中。

  • job：一个workflow由多个job构成。

  • step：每个job分为多个步骤。

  • action：每个步骤执行的具体动作。

字段解释

runs-on

  • ubuntu-latest

  • windows-latest

  • macos-latest
