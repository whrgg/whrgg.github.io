2025.07 — 2026.04AI 应用开发实习生

深圳市兆诺恒基网络科技有限公司

负责企业内部 RAG 知识库问答核心链路，搭建高可用检索、流式切分管道与权限隔离。

  • 两阶段混合检索：Dense 向量召回（KNN 窗口 topK×30）+ 关键词 must + BM25 加权重排（0.2 / 1.0）；Embedding 异常时熔断，切到全文检索。
  • Apache Tika 流式解析大文档，JVM 内存 >80% 时背压拦截；子块按「段落 → 句子 → HanLP → 字符」四级降级，批量重试 3 次。
  • 5MB 分片并发上传，Redis Bitmap 追分片状态，MinIO 异步合并；文件 MD5 做秒传与去重。
  • 检索前用 Redis 展开组织与岗位标签，在 ES / 向量层注入个人、本组织、公开制度的复合过滤，避免跨部门越权召回。
  • 离线评测 45 条 Query / 133 条切片；专名 Recall@5 达 0.843，语义类由 0.867 调至 0.767，用数据做消融。
