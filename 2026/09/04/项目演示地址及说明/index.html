Lvren 终端 Agent

打开 http://106.14.29.104:8443/，用上面的账号登录。

这是隔离 Linux 容器里的真实 CLI，不是录屏。工作区有一个故意留了 bug 的小项目「Station」，可以让 Agent 读代码、跑测试、改文件。容器看不到宿主机博客、家目录和 Docker socket。

源码：github.com/whrgg/Lvren

澄知 Clarity · 知识库 RAG

打开 http://106.14.29.104，用上面的账号登录。第一次打开可能要等 2–5 秒，是演示机配置，不是页面坏了。

最短走通：

  1. 登录后进入聊天页，直接问和已有文档相关的问题。
  2. 若想自己试：左侧进知识库，上传一份短的 PDF / Word / txt，组织标签选默认可用的那一项，等状态变成「完成」再去问。

回车发送，Ctrl + Enter 换行。回答会流式出现；引用了知识库时，句末会带来源标记。

说明

  • 演示机内存较小，偶发变慢等十几秒再试即可。
  • 登录不上：确认账号密码没有空格，强制刷新一次。
  • 澄知问了说「暂无相关信息」：先确认知识库里文件状态已完成，再换成文档里真正出现过的词。
  • 这是可运行的演示，不是完整商业产品。
